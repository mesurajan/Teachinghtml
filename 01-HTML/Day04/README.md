# Day 04 - HTML Tables and Forms

## Summary

On Day 04, we learned how websites display structured data using tables and
collect information from users using forms. The practice page combines a student
information table with a feedback form.

## Topics Covered

### HTML Tables

- Creating a table using `<table>`
- Creating rows using `<tr>`
- Creating heading cells using `<th>`
- Creating data cells using `<td>`
- Using a table to organize related information into columns and rows

### HTML Forms

- Creating a form using `<form>`
- Describing fields using `<label>`
- Text inputs using `type="text"`
- Email inputs using `type="email"`
- Telephone inputs using `type="tel"`
- Number inputs using `type="number"`
- Radio buttons for selecting one option
- Checkboxes for selecting multiple options
- Multi-line messages using `<textarea>`
- Submit controls using `<input type="submit">` and `<button>`
- Introducing dropdown menus using `<select>` and `<option>`

## Work Completed

The `index.html` page contains:

1. A student information table with serial number, name, course, and contact
   columns.
2. A feedback form that asks for personal details, gender, favorite food, and a
   message.
3. A commented dropdown example for future form practice.

## Main Learning Outcome

By the end of Day 04, students can represent data clearly in a table and build
a form containing several common input types.

## Practice Ideas

- Add more students to the table.
- Add a table caption and table sections.
- Connect every label to its input using matching `for` and `id` values.
- Add a course dropdown to the feedback form.
- Make important form fields required.
