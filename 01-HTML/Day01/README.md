# Day 01 - Introduction to HTML

## Summary

On Day 01, we learned the basic structure of an HTML document and created a
simple **About Me** webpage. This was the first step toward understanding how a
browser reads HTML and displays webpage content.

## Topics Covered

- What HTML is and why it is used
- The `<!doctype html>` declaration
- The `<html>`, `<head>`, `<title>`, and `<body>` elements
- Headings from `<h1>` to `<h5>`
- Paragraphs using `<p>`
- Line breaks using `<br>`
- Horizontal lines using `<hr>`
- Opening tags, closing tags, and nesting

## Work Completed

The `aboutme` folder contains two beginner HTML pages:

- `aboutme/test.html` practices headings, paragraphs, line breaks, and horizontal
  lines.
- `aboutme/index.html` is a more complete About Me page containing personal
  information, address, contact details, and education.

## Main Learning Outcome

By the end of Day 01, students can create a valid HTML file, add text content
using headings and paragraphs, and organize a simple personal webpage.

## Practice Ideas

- Add a hobbies section to the About Me page.
- Add more education details using headings and paragraphs.
- Change the browser tab title using the `<title>` element.
- Practice using all six heading levels in the correct order.
