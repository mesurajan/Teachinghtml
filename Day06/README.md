# Day 06 - Semantic Event Management Website

## Summary

On Day 06, we created a complete beginner-friendly **Event Management Website**
using only HTML. The project focuses on website architecture, consistent
navigation, semantic structure, tables, forms, and organizing related files.

No CSS or JavaScript is used in this project.

## Topics Covered

- Planning a complete multi-page website
- Organizing pages and images into folders
- Creating consistent navigation on every page
- Using semantic HTML elements:
  - `<header>`
  - `<nav>`
  - `<main>`
  - `<section>`
  - `<footer>`
- Displaying event information with paragraphs and lists
- Displaying schedules using tables
- Collecting registration data using forms
- Connecting labels and form controls
- Using radio buttons, checkboxes, dropdowns, and textareas
- Writing useful image `alt` text
- Creating email and telephone links

## Work Completed

The `event-management` folder contains the full Student Innovation Event 2026
website:

- `index.html` is the detailed homepage with event statistics, activities,
  audience information, partner placeholders, and registration links.
- `about.html` explains the event, its purpose, and reasons students should
  participate.
- `schedule.html` uses a table to display seven event activities with their
  times and venues.
- `register.html` contains a complete registration form for student details,
  gender, college, course, interests, and messages.
- `contact.html` presents the organizer's address, telephone number, email, and
  office hours.
- `gallery.html` contains event photographs, captions, detailed guest speaker
  profiles, and competition categories.
- The `images/` folder contains suitable local images used across all pages.

## Website Architecture

Every page follows the same basic structure:

```html
<header>
  <nav></nav>
</header>
<main></main>
<footer></footer>
```

The same navigation menu appears on every page so visitors can move between
Home, About, Schedule, Register, and Contact.

## Main Learning Outcome

By the end of Day 06, students can plan and build a connected, semantic,
multi-page HTML website that represents information and collects user data.
