# Day 02 - Text Formatting, Lists, Links, and Images

## Summary

On Day 02, we expanded our basic HTML knowledge by learning how to format text,
create lists, connect pages using links, and display images. We also started a
small multi-page restaurant website named **Mero Khaja Ghar**.

## Topics Covered

- Bold text using `<b>` and important text using `<strong>`
- Italic text using `<i>` and emphasized text using `<em>`
- Underlined text using `<u>`
- Ordered lists using `<ol>`
- Unordered lists using `<ul>`
- List items using `<li>`
- External and internal links using `<a>`
- Opening links in a new tab using `target="_blank"`
- Images using `<img>`
- Relative and absolute file paths
- Connecting multiple HTML pages with navigation links

## Work Completed

### Classroom Practice

The main `index.html` demonstrates text formatting, ordered lists, unordered
lists, and links. The `pages` folder contains additional pages used to practice
navigation between files.

### Mero Khaja Ghar Project

The `task` folder contains a beginner multi-page restaurant website:

- `task/index.html` is the homepage and displays restaurant images.
- `task/About.html` is the About page.
- `task/Menu.html` is the menu page.
- `task/contact.html` is the contact page.
- `task/assets/image01.jpg` is a locally stored website image.

Every restaurant page includes a navigation list connecting Home, About, Menu,
and Contact.

## Main Learning Outcome

By the end of Day 02, students can format text, organize information with lists,
add images, and build navigation that connects multiple HTML pages.

## Practice Ideas

- Complete the food items and descriptions on the Menu page.
- Add restaurant information to the About page.
- Add phone, email, and address details to the Contact page.
- Add another local image inside the `assets` folder.
