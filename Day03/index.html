What Is a Multi-Page Website?

A multi-page website is a collection of related HTML files. Each page is stored as a separate file and opens when a visitor clicks a link.

A simple restaurant website can contain these pages:

  • index.html: The homepage
  • about.html: Information about the restaurant
  • menu.html: Food items and descriptions
  • contact.html: Address and contact information

Organizing Website Files

Keeping files organized makes links and image paths easier to understand. 

Restaurant-Website/
|-- index.html
|-- about.html
|-- menu.html
|-- contact.html
`-- images/
    |-- burger.jpg
    `-- interior.jpg

Shared images should be placed inside the images folder and should have clear filenames.

Website Navigation

Navigation helps visitors move between website pages. A multi-page website should use the same navigation links on every page.

Example Navigation

<ul>
  <li><a href="index.html">Home</a></li>
  <li><a href="about.html">About</a></li>
  <li><a href="menu.html">Menu</a></li>
  <li><a href="contact.html">Contact</a></li>
</ul>

Relative Paths

Relative paths connect files based on their location inside the project folder.

  • about.html links to a file in the same folder.
  • images/burger.jpg loads an image from the images folder.
  • File names and letter case must match correctly.

Using Images Correctly

Images can make a website more informative. Every image should have a correct path and useful alternative text. 

<figure>
  <img src="images/burger.jpg" alt="Cheesy burger with lettuce" width="300">
  <figcaption>Our special cheesy burger</figcaption>
</figure>

The alt attribute describes the image when it cannot be displayed and helps visitors using screen readers.

Class Task: Improve the Restaurant Website

  1. Use the same navigation links on every page.
  2. Test every link from every page.
  3. Add menu images with correct paths and alt text.
  4. Add the restaurant story and mission to the About page.
  5. Add location, phone number, and email to the Contact page.

Homework: Student Event Website

Create a multi-page website for a college event.

  • Home page
  • About Event page
  • Schedule page with at least five events
  • Contact page

Every page should use identical navigation and clean HTML structure.
