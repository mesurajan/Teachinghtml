# Day 03 - Building Multi-Page Websites Using HTML

## Summary

On Day 03, we learned how separate HTML files work together to create a
multi-page website. The lesson focused on organizing project files, creating
consistent navigation, using relative paths, and adding images correctly.

The topics and tasks in this folder follow the provided **HTML Day 3: Building
Multi-Page Websites Using HTML** presentation.

## Topics Covered

- Understanding what makes a website multi-page
- Organizing HTML pages and images into a clear folder structure
- Connecting pages using anchor links
- Creating the same navigation menu on every page
- Understanding relative file paths
- Adding images using correct `src` paths
- Writing meaningful image `alt` text
- Using `<figure>` and `<figcaption>`
- Testing links and image paths in the browser

## Work Completed

The `index.html` page is a simple classroom-practice page that explains and
demonstrates:

1. The purpose of a multi-page website.
2. A recommended restaurant website folder structure.
3. A reusable navigation menu using `<ul>` and `<a>`.
4. Relative links for pages and images.
5. Accessible images with alt text and captions.
6. The restaurant website class task.
7. The student event website homework task.

## Recommended Multi-Page Structure

```text
Restaurant-Website/
|-- index.html
|-- about.html
|-- menu.html
|-- contact.html
`-- images/
    |-- burger.jpg
    `-- interior.jpg
```

## Class Task

Improve the restaurant website created during Day 02:

- Make the navbar identical on every page.
- Test every navigation link.
- Add menu images with proper paths and alt text.
- Add a restaurant story and mission to the About page.
- Add the location, phone number, and email to the Contact page.

## Homework

Create a multi-page student event website containing:

- `index.html` for the event homepage
- `about.html` for detailed event information
- `schedule.html` with an ordered list of at least five events
- `contact.html` with college and contact information

Every homework page should contain the same navigation menu and link correctly
to the other pages.

## Project Structure

```text
Day03/
|-- README.md
`-- index.html
```

## Main Learning Outcome

By the end of Day 03, students can organize a small website, connect multiple
HTML pages using relative links, reuse consistent navigation, and reference
images from an images folder.

## Practice Ideas

- Copy the same navigation menu to every new page.
- Create an `images` folder and add suitable restaurant images.
- Add an optional gallery page with at least five images.
- Test every link and image path before completing the project.
